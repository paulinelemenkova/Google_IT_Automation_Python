# Google IT Automation with Python — Coursera Exercises

Personal exercise scripts and solutions completed during the **Google IT Automation with Python** Professional Certificate on Coursera (developed by Google). The scripts follow the hands-on curriculum on writing Python for IT support and systems-administration automation, and include the author's inline learning notes.

Completed by **Polina Lemenkova** on 8 April 2026.

## Professional Certificate

The seven-course program covers:

1. Crash Course on Python
2. Using Python to Interact with the Operating System
3. Introduction to Git and GitHub
4. Troubleshooting and Debugging Techniques
5. Configuration Management and the Cloud
6. Automating Real-World Tasks with Python
7. Accelerate Your Job Search with AI

## Topics covered

Python fundamentals; interacting with the operating system (files and directories, CSV, regular expressions, environment variables); standard I/O streams and subprocess; logging and log parsing; troubleshooting, testing and unit testing; type hints; and automating real-world tasks.

## Scripts

- `generate_report.py` — reads employee data from a CSV file and generates a report (real-world automation task)
- `script_0326_venv.py` — creating and using Python virtual environments (venv)
- `script_0327_csv_files.py` — reading and writing CSV files with the csv module
- `script_0327_files_directories.py` — managing files and directories with os and pathlib
- `script_0327_regex.py` — regular expressions with the re module
- `script_0329.py` — navigating files and directories (os / pathlib)
- `script_0329_.py` — type hints and annotations (typing)
- `script_0329_env_var.py` — reading environment variables
- `script_0329_exec_file.py` — creating and executing script files
- `script_0329_inp_fun.py` — getting user input with input()
- `script_0329_log_files.py` — parsing and filtering log files
- `script_0329_reading_data.py` — reading data from files
- `script_0329_standard_streams.py` — standard input / output / error streams
- `script_0329_subproc.py` — running shell commands with the subprocess module
- `script_0329_sys_com.py` — system commands via sys / os
- `script_0329_test_exp.py` — writing test expressions and assertions
- `script_0329_testing.py` — software testing basics
- `script_0329_time_convert.py` — date and time conversion (datetime)
- `script_0329_unittest.py` — unit testing with the unittest framework
